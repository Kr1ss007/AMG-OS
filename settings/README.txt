settings — Central System Settings Application
================================================================================
First-class native AMGOS configuration app:
- Single place where all user-facing settings live
- Organized by topic (Display, Sound, Network, Touchpad, Keyboard,
  Accessibility, Privacy, Appearance, Updates)
- OTA updates delivered cleanly without external packages or terminal tools
- Writes to Process 1 signed configuration state (never writes files directly)
================================================================================
