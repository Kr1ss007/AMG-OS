TEST-SUITE
================================================================================
AMGOS Test Suite Specifications and Observational Protocols.

Contains plain-English test specifications and verified run results:
- boot/: Boot sequence, silence, framebuffer continuity, chime timing
- ipc/: Two-process boundary enforcement and pub/sub reliability
- compositor/: Wayland-only validation, cubic-bezier animations, Global Menu
- primary-app/: Pathfinder search, package inspection/install, browser embed
- hardware/: Reference hardware validation protocol
- wizard/: Setup wizard flow and signed state output
- regression/: Guard tests against fixed bugs
================================================================================
